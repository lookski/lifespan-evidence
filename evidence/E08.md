# E08. 全谷物与死亡 (剂量反应 meta)

## 一句话结论

每天每多 90 g (3 份) 全谷物, 全因死亡风险下降 17%; 精制谷物与白米未见关联——
"谷物要看加工度, 不看总量"。

## 研究设计与人群

- 设计: 45 项前瞻研究 (64 篇文献) 系统综述 + 剂量反应 meta, 检索至 2016-04
- 暴露: 全谷物每 +90 g/天 (3 份, 如 2 片全麦面包 + 1 碗燕麦); 同时分析精制谷物/白米/总谷物
- 终点: 冠心病, 卒中, 心血管病, 总癌症, 全因死亡, 呼吸病/糖尿病/感染病死亡

## 关键数字 (机器核验, 摘要原文)

**每 +90 g/天 全谷物:**

| 终点 | RR (95% CI) |
|---|---|
| 冠心病 | 0.81 (0.75-0.87) |
| 心血管病 | 0.78 (0.73-0.85) |
| 总癌症 | 0.85 (0.80-0.91) |
| 全因死亡 | **0.83 (0.77-0.90)** |
| 呼吸病死亡 | 0.78 (0.70-0.87) |
| 糖尿病死亡 | 0.49 (0.23-1.05, 不显著) |

- 剂量上限: 大部分终点的收益到 **210-225 g/天 (7-7.5 份)** 仍在增加
- 阴性结果: 精制谷物, 白米, 总谷物与死亡未见显著关联

## 剂量反应与可执行解读

- 90 g 全谷物 ≈ 2 片全麦面包 + 1 碗燕麦粥; 中国语境: 糙米/燕麦/小米/全麦面替换部分白米白面
- 可执行: 全谷物占总谷物一半以上是务实的起步点; 逐步替换而非一步到位 (肠胃需要适应)

## 证据强度与局限性

- 优势: 研究数多 (45 项), 与精制谷物对照设计能分离"加工度"效应
- 局限: 观察性; "全谷物"定义在各研究间不一致 (自报到标签法); 高全谷物摄入者整体饮食模式
  更健康; 白米的阴性结果部分源于亚洲人群白米摄入高但总体死亡风险不同 (生态混杂)

## 与其他证据的一致性

- 与 E04/E05 (MedDiet 全谷物基底) 一致; Circulation 2016 与 AJCN 2016 两篇同年 meta 结论相同
- 与 E10 (植物蛋白) 共同支持"用完整植物食物替换精制碳水与红肉"的总策略
