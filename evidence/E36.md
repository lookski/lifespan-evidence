# E36. 膳食/血浆维 C 与心血管死亡 (meta)

## 一句话结论

320,548 人 18 项前瞻研究: 膳食维 C 最高组心血管死亡 RR 0.79, 血浆维 C 最高组 RR 0.60——
但这是"吃蔬果多的人更健康"的相关性; 因果性检验见 E38-E40 (全部为阴性)。

## 研究设计与人群

- 设计: 15 项前瞻队列 + 3 项干预研究的观察性评估, 320,548 人, 16,974 例 CVD 死亡,
  剂量反应 meta (检索至 2017-10)
- 暴露: 膳食维 C 摄入与血浆维 C 浓度, 最高 vs 最低类
- 终点: 总心血管死亡

## 关键数字 (机器核验, 摘要原文)

| 暴露 | CVD 死亡 RR (95% CI) |
|---|---|
| 膳食维 C 最高 vs 最低 | **0.79 (0.68-0.89)**, I²=46% |
| 血浆维 C 最高 vs 最低 | **0.60 (0.42-0.78)**, I²=65% |
| 膳食维 E | 0.91 (0.79-1.03) 不显著 |
| 血浆 α-生育酚 | 0.82 (0.76-0.88) |
| 膳食 β-胡萝卜素 | 0.89 (0.73-1.05) 不显著 |

- 循环 (血浆) 标志物的关联强于膳食摄入 (生物标志物更客观, 但也更受吸烟/炎症影响)

## 剂量反应与可执行解读

- 观察性强弱排序: 血浆维 C > 膳食维 C > 其他抗氧化剂——维 C 是蔬果摄入的忠实标志物
- 可执行: 把它读作"多吃蔬果的证据" (E06), 而非"补维 C 的证据"; 血浆维 C 充足线
  (E37) 为 >28 µmol/L, 靠每天蔬果即可达成

## 证据强度与局限性

- 优势: 32 万人, 膳食与血浆双暴露设计, 与其他抗氧化剂对照
- 局限: 观察性; 血浆维 C 受吸烟/炎症/ socioeconomic status 影响 (强混杂);
  单次血样代表长期暴露的能力有限

## 与其他证据的一致性

- 与 E06 (蔬果 0.90) 方向一致, 维 C 是其成分之一
- 与 E38 (MR 无因果), E39/E40 (RCT 无效) 构成完整的"相关-因果-干预"三层检验:
  观察阳性 → 因果阴性 → 干预无效, 教科书级的标志物陷阱
