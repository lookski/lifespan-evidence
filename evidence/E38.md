# E38. 基因高血浆维 C 与死亡 (孟德尔随机化)

## 一句话结论

97,203 人基因分型: 遗传决定的血浆维 C 升高 11% 与缺血性心脏病及全因死亡无显著因果关联
(CI 跨 1.0)——观察性关联的"维 C 假说"过不了因果检验第一关。

## 研究设计与人群

- 设计: 孟德尔随机化 (MR), 工具变量 = SLC23A1 rs33972313 (钠依赖维 C 转运体 1 基因),
  G 等位基因携带者血浆维 C 高 11%
- 人群: 97,203 名白人 (丹麦哥本哈根研究), 其中 10,123 例缺血性心脏病, 8,477 例死亡;
  血浆维 C 实测 3,512 人, 膳食信息 83,256 人
- 终点: 缺血性心脏病, 全因死亡

## 关键数字 (机器核验, 摘要原文)

- 工具变量强度: G 等位基因与血浆维 C +11% (F 统计量合格)
- 阳性对照 (蔬果摄入本身): 最高 vs 最低蔬果摄入, 缺血性心脏病 HR 0.87 (0.78-0.97),
  全因死亡 HR 0.80 (0.73-0.88)——关联真实
- **MR (因果检验): 基因高维 C 与缺血性心脏病及全因死亡关联的 95% CI 均跨 1.0**,
  不显著; 作者结论: "无法排除蔬果获益部分由维 C 驱动, 但按效应量也无法确认"

## 剂量反应与可执行解读

- MR 逻辑: 基因随机分配的"终身血浆维 C 高 11%"若不能降低死亡, 那么观察性关联里的
  维 C 成分主要是混杂 (蔬果包里的其他成分 + 吃蔬果者的生活方式)
- 可执行: 不改变行为建议 (蔬果照吃, E06), 但降低"维 C 补剂延寿"的先验期望

## 证据强度与局限性

- 优势: 基因变异终生固定, 随机分配, 免于常见混杂与逆向因果
- 局限: 单一 SNP 工具变量解释变异小 (弱工具偏倚方向不明确); 丹麦白人人群; MR 估计的
  是"终生缓释"暴露, 与补剂脉冲式暴露不同; 检验效能对 11% 的暴露差异偏小
  (作者亦承认 CI 宽导致推断困难)

## 与其他证据的一致性

- 与 E36/E37 (观察性阳性) 与 E39/E40 (RCT 阴性) 构成三层检验的中间层
- 类似结构: β-胡萝卜素的 MR 与 RCT 均阴性 (E39 中 β-胡萝卜素甚至增加死亡)

Kobylecki CJ, et al. Genetically high plasma vitamin C, intake of fruit and vegetables,
and risk of ischemic heart disease and all-cause mortality: a Mendelian randomization
study. **Am J Clin Nutr** (营养学第一梯队, 美国营养学会会志) 2015;101(6):1213-1222. doi:10.3945/ajcn.114.104497
(PMID 25948669).
