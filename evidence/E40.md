# E40. 维生素 C 直接 RCT (PHS II: 心血管 + 癌症双终点)

## 一句话结论

14,641 名男医生 8 年双盲 RCT: 500 mg/d 维 C 对主要心血管事件 (HR 0.99), 心血管死亡
(1.02), 全因死亡 (1.07), 总癌症 (1.01) 全部无显著影响——维 C 补剂延寿/防病的直接
检验为零获益。

## 研究设计与人群

- 设计: Physicians' Health Study II, 随机, 双盲, 安慰剂对照, 2×2 因子设计
  (维 E 400 IU 隔日 × 维 C 500 mg/日)
- 人群: 14,641 名 50+ 美国男医生 (5.1% 有基线心血管病; 癌症分析含 1,307 名既往癌)
- 干预时长: 1997-08-31 至 2007-08-31, 平均随访 8.0 年
- 终点: 主要心血管事件 (心梗/卒中/CVD 死亡), 前列腺癌, 总癌症; 全因死亡 (安全性)

## 关键数字 (机器核验, 摘要原文)

**心血管 (JAMA 2008):**

| 终点 | 维 C HR (95% CI) |
|---|---|
| 主要心血管事件 | **0.99 (0.89-1.11)** |
| 心梗 | 1.04 (0.87-1.24) |
| 卒中 | 0.89 (0.74-1.07) |
| 心血管死亡 | 1.02 (0.85-1.21) |
| 全因死亡 | 1.07 (0.97-1.18) |

**癌症 (JAMA 2009):**

| 终点 | 维 C HR (95% CI) |
|---|---|
| 总癌症 | **1.01 (0.92-1.10)** |
| 前列腺癌 | 1.02 (0.90-1.15) |

- 对照组维 E: 同样无获益, 且出血性卒中风险增加 (HR 1.74, 1.04-2.91)——
  "天然维生素"也会伤人
- 依从性调整与剔除前 4-6 年随访 (去逆向因果) 均不改变结论

## 剂量反应与可执行解读

- 500 mg/日已远超 RDA (90 mg 男/75 mg 女), 是普通多维片的 5 倍——超生理剂量照样无效
- 可执行: 不为延寿/防病服用维 C 补剂 (除非缺乏, 见 E43 场景); 500 mg 级日常补充
  虽未显示害处, 但也无意义; 食物维 C (E06) 是正解

## 证据强度与局限性

- 优势: 大样本长时程双盲 RCT, 双终点 (CV + 癌), 依从性验证 (血抗氧化水平),
  因子设计同时检验两种维生素
- 局限: 男性医生 (健康职业人群, 低基线风险——"低危人群难显效"论证); 非寿命终点;
  500 mg 非大剂量静脉场景; 女性未测

## 与其他证据的一致性

- 与 E39 (meta: 维 C 中性) 完全一致; 与 E38 (MR 阴性) 一致; 与 E41 (重症大剂量无效)
  一致——维 C 补剂在从健康人到危重病人的全谱系上都没有生存获益
