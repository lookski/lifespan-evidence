# E41. 大剂量静脉维生素 C 与脓毒症 (CITRIS-ALI + VICTAS)

> 层级: [← 总结 README](../README.md) · [维度速览 09-vitamin-c](../topics/09-vitamin-c.md) · 本页 `E41`

## 一句话结论

两项高质量 RCT: 脓毒症/ARDS 重症患者静脉大剂量维 C 对器官衰竭评分, 呼吸机脱离日,
30 天死亡率均无显著改善——"维 C 是救命神药"的重症版神话也被 RCT 证伪。

## 研究设计与人群

- CITRIS-ALI (JAMA 2019): 7 个 ICU, 167 名脓毒症+ARDS (<24h) 患者, 随机静注维 C
  50 mg/kg q6h ×96h vs 安慰剂; 主终点: 96h SOFA 评分变化与炎症/血管损伤标志物
- VICTAS (JAMA 2021): 43 家医院, 501 名脓毒症呼吸/循环功能障碍患者, 随机维 C 1.5 g +
  硫胺素 100 mg + 氢化可的松 50 mg q6h ×96h vs 安慰剂; 主终点: 30 天呼吸机与升压药
  脱离日 (因经费原因提前终止, 欠功效)

## 关键数字 (机器核验, 摘要原文)

**CITRIS-ALI:**
- SOFA 评分变化: 维 C 组 9.8→6.8 (3 分) vs 安慰剂 10.3→6.8 (3.5 分), 差值 -0.10
  (95% CI -1.23 至 1.03), **P=0.86**
- CRP: 差值 +7.94 µg/mL (-8.2 至 24.11), P=0.33; 血栓调节蛋白: +0.69 ng/mL, P=0.70

**VICTAS:**
- 呼吸机/升压药脱离日: 中位 25 天 (IQR 0-29) vs 安慰剂 26 天 (0-28), 差值 -1 天
  (-4 至 2), **P=0.85**
- 30 天死亡率: 22% vs 24% (无显著差异)

## 剂量反应与可执行解读

- 50 mg/kg q6h ≈ 每日 20-30 g 静注 (普通口服剂量的百倍), 连续 4 天, 仍无终点改善
- 可执行: 病人与家属不需要在 ICU 追加"维 C 豪华套餐"; 医生按指南用药; 
  "Marik 方案" (维 C+硫胺素+氢化可的松) 的流行早于其证据成熟, VICTAS 与
  Chen 2022 等后续 RCT 未支持其硬终点获益

## 证据强度与局限性

- 优势: 双盲安慰剂对照, 重症标准终点, 两项独立试验方向一致
- 局限: CITRIS-ALI 样本 167 人; VICTAS 提前终止欠功效; 静注时机 (24h 内) 已相当早;
  仍不能排除特定亚组 (维 C 缺乏的重症患者) 获益, 但证据未显示

## 与其他证据的一致性

- 与 E39/E40 (口服维 C 无效) 形成完整链条: 健康人口服无效 → 医生人群口服无效 →
  危重病人静注大剂量也无效
- 与 E43 (感冒) 一致: 维 C 的"免疫增强"公众叙事在 RCT 层面全面落空
