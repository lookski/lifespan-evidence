# E42. 大剂量维 C 补剂与肾结石 (安全性)

## 一句话结论

瑞典男性队列 + meta: 男性服用 ≥1000 mg/d 抗坏血酸补剂者肾结石风险显著升高
(250-499 mg/d 即有正相关 OR 1.14), 女性不显著——大剂量维 C 补剂不仅无效 (E39-E41),
在男性中还可能带来肾结石代价。

## 研究设计与人群

- 设计 A (队列): COSM (Cohort of Swedish Men) 45-79 岁男性前瞻队列 (JAMA Intern Med
  2013 短篇报告), 比较服用维 C 补剂者与不服用者的肾结石发生率
- 设计 B (meta): 4 项研究, 男女分别分析, 剂量分层 (250-499 / 500-999 / 1000-1499 /
  >1500 mg/d) (Urol J 2019)
- 终点: 肾结石发病 (多为草酸钙结石)

## 关键数字 (机器核验, 摘要原文)

**Urol J 2019 meta (4 项研究):**

| 剂量段 | 男性 OR (95% CI) | 女性 OR (95% CI) |
|---|---|---|
| 250-499 mg/d | **1.14 (1.00-1.28)** 显著 | 1.00 (0.82-1.22) 不显著 |
| 1000-1499 mg/d | **1.12 (1.11-1.13)** 显著 | 0.99 (0.90-1.08) 不显著 |
| >1500 mg/d | 1.20 (0.99-1.46) 边缘 | 1.08 (0.99-1.18) 边缘 |

- 男性 vs 女性: 男性服用补剂者肾结石风险显著更高 (OR 1.62, 1.09-2.42, P=0.02)
- COSM 队列 (2013): ≥1000 mg/d 补剂者肾结石风险显著高于非服用者 (该刊短篇报告,
  具体调整 HR 见原文正文, 摘要无数字未核验)
- 机制: 维 C 体内代谢为草酸盐 → 高草酸尿 → 草酸钙结石

## 剂量反应与可执行解读

- 男性敏感, 女性不敏感的机制未完全确定 (激素/尿路解剖/饮食结构差异假说)
- 可执行: 男性避免长期 ≥1000 mg/d 维 C 补剂; 有肾结石史者任何剂量补剂前咨询;
  泡腾片 (常 1000 mg/片) 是常见踩坑点; 食物维 C 无此风险 (剂量低且伴随钾/枸橼酸)

## 证据强度与局限性

- 优势: 有前瞻队列与 meta 两层, 机制明确 (草酸盐), 剂量分层清晰
- 局限: 观察性; 自报补剂使用; 结石为自报或就诊记录 (漏报轻症); COSM 短篇报告
  详细数字在正文; 女性数据少

## 与其他证据的一致性

- 与 E39-E41 (无效) 合并成完整决策: 无效 + 潜在害处 → 不推荐大剂量维 C 补剂
- 与 E06 (食物维 C/蔬果有效) 不冲突——剂量与载体不同
