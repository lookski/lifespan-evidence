# E43. 维生素 C 与感冒 (Cochrane)

## 一句话结论

29 项试验 11,306 人: 常规补维 C 不能预防普通人群感冒; 已规律补充者感冒病程缩短
成人 8%, 儿童 14%; 剧烈体力活动人群 (马拉松/滑雪/士兵) 感冒风险 RR 0.48——
维 C 对感冒"预防和治疗均不给力, 唯特宜人群与病程缩短例外"。

## 研究设计与人群

- 设计: Cochrane 系统综述 (2013 版, 29 项 RCT, 11,306 人), 区分常规补充与治疗性服用
- 暴露: 常规维 C 补充 (≥0.2 g/d) vs 安慰剂; 感冒起病后治疗性服用
- 终点: 感冒发生率, 病程, 严重度
- 特宜人群亚组: 马拉松/滑雪/亚北极训练士兵 (5 项试验, 598 人)

## 关键数字 (机器核验, 摘要原文)

- **普通人群预防**: 常规补充不降低感冒发生率 (合并 RR 见原文, 不显著)
- **病程** (31 项比较, 9,745 次感冒): 成人缩短 **8% (3%-12%)**, 儿童 **14% (7%-21%)**;
  儿童每天 1-2 g 缩短 18%
- **特宜人群**: 5 项试验 598 人, 感冒风险 **RR 0.48 (0.35-0.64)** (降 52%)
- 治疗性服用 (感冒后才开始): 病程与严重度无一致效应
- 作者结论: 常规补充对普通人群不获支持; 但补充低成本且安全, 感冒者可个体化试用

## 剂量反应与可执行解读

- 病程缩短 8% ≈ 感冒 7 天变 6.5 天, 幅度小; "感冒了再吃"无效 (需要预先饱和血浆维 C)
- 可执行: 不必为感冒常规吃维 C; 马拉松/滑雪/高强度军训等极端体力消耗场景可考虑
  预先补充; 儿童 1-2 g/d 短期数据相对好 (仍需医生指导); 大剂量注意 E42 (男性肾结石)

## 证据强度与局限性

- 优势: Cochrane 方法学, 区分常规 vs 治疗性服用 (概念澄清), 特宜人群亚组有清晰生物学
  解释 (剧烈运动时中性粒细胞维 C 消耗)
- 局限: 病程缩短为小效应; 试验年代久 (多为 1970-90s), 营养基线不同; 出版偏倚检查
  提示部分不对称; 剂量异质

## 与其他证据的一致性

- 与 E39-E42 合并为维 C 的完整画像: 不延寿 (E39/E40), 不救命 (E41), 有肾结石风险
  (E42), 感冒微弱获益 (本条目)——除缺乏症治疗外, 维 C 补剂没有强适应证
- 与 E36-E38 (食物维 C 相关但无因果) 一致: 好处在食物不在药片

Hemilä H, Chalker E. Vitamin C for preventing and treating the common cold.
**Cochrane Database Syst Rev** 2013;1:CD000980. doi:10.1002/14651858.CD000980.pub4
(PMID 23440782).
