# E47. 生命八要素 (LE8, AHA 科学咨询)

## 一句话结论

AHA 2022 把"简单生活七要素"升级为"生命八要素" (LE8), 新增睡眠健康; LE8 分数越高,
全因死亡/心血管死亡/预期寿命均越高 (NHANES 联动数据)——它是本目录 E01-E35 全部
单项证据的官方打包框架。

## 研究设计与人群

- 设计 A (框架): AHA 科学咨询 (Circulation 2022), 4 健康行为 + 4 健康因素:
  饮食 (Life's Essential 8 饮食工具), 体力活动, 尼古丁暴露, 睡眠; BMI, 血脂,
  血糖, 血压
- 设计 B (验证): NHANES 2005-2018 联动死亡登记, 23,653 名成人 (≥20 岁), 中位随访
  7.6 年, LE8 连续分数与死亡终点
- 每项 0-100 分, 总分 0-100, 四级 (低/中/高/理想)

## 关键数字 (机器核验, 摘要原文)

**NHANES 联动验证 (每 +10 分 LE8):**

| 终点 | aHR (95% CI) |
|---|---|
| 全因死亡 | **0.79 (0.75-0.83)** |
| 心血管死亡 | 0.76 (0.68-0.86) |
| 癌症死亡 | 0.76 (0.66-0.88) |
| 呼吸病死亡 | 0.74 (0.61-0.90) |

- 50 岁时 LE8 高 vs 低: 预期总寿命差异 **+7.4 年** (CV 死亡自由寿命 +5.2 年)
- 与 E01 (低风险生活方式 +8.8/+8.1 年) 量级一致——不同队列, 不同定义, 收敛到同一区间

## 剂量反应与可执行解读

- 8 要素中饮食用"健康饮食工具"评分 (16 项: 蔬果/全谷/豆/坚果/加工肉/SSB/红肉/鱼
  等), 与本目录 E04-E14 的单项证据一一对应
- 可执行: 用 LE8 自测 (在线工具) 得到基线分数 → 逐项改善; 弱项通常是饮食细节与
  睡眠规律性 (E25); 医疗因素 (血压/血糖/血脂/BMI) 靠体检监测 + 生活方式 + 必要时用药

## 证据强度与局限性

- 优势: 官方框架 + 大样本验证 + 与 E01/E02 独立收敛
- 局限: LE8 分数是事后归纳 (各要素权重等权未必最优); 饮食子分数受自报偏倚影响;
  NHANES 短期随访; 心理社会因素 (E31-E35) 未纳入——LE8 覆盖身体但不覆盖心灵

## 与其他证据的一致性

- 是 E01-E35 的"证据汇编视角"; 与 E48 (痴呆 14 因素) 相比, LE8 是心血管导向,
  后者是脑健康导向——两者交集很大 (运动/血压/血糖/肥胖/吸烟/饮食)
- 与 E49 (GBD 可控风险) 一致: 八要素中的行为项正是全球早死的首要可控因素
