# E49. 全球可控风险负担 (GBD 2021)

> 层级: [← 总结 README](../README.md) · [维度速览 12-frameworks](../topics/12-frameworks.md) · 本页 `E49`

## 一句话结论

GBD 2021: 全球疾病负担的首要可控风险是**环境颗粒物空气污染** (占全部 DALY 的 8.0%),
其次高收缩压 (7.8%), 吸烟 (5.7%), 低出生体重与早产 (5.6%), 高空腹血糖 (5.4%)
——延寿的"人口层"优先级与个体层 (E01/E47) 指向同一张清单。

## 研究设计与人群

- 设计: GBD 2021 风险因素系统分析, 88 项风险因素, 204 个国家与 811 个次国家级地区,
  1990-2021, 631 个"风险-结局"配对 (GBD 标准比较风险框架)
- 数据来源: 54,561 个独立来源
- 输出: 归因 DALY 与归因死亡, 按 SDI 五分位分层, 附 BPRF 保守解释
- 人群: 全年龄分层 (0-4, 5-14, ..., 75+)

## 关键数字 (机器核验, PMID 38762324 摘要原文)

**2021 年各风险占全部 DALY 的百分比 (摘要原文口径, 括号内为 95% UI):**

| 风险因素 | 占全部 DALY |
|---|---|
| 环境颗粒物空气污染 | **8.0% (6.7-9.4)** -- 居首 |
| 高收缩压 (SBP) | 7.8% (6.4-9.2) |
| 吸烟 | 5.7% (4.7-6.8) |
| 低出生体重与短 gestation | 5.6% (4.8-6.3) |
| 高空腹血糖 (FPG) | 5.4% (4.8-6.0) |

**2000-2021 年的结构变化:**

- 行为风险的归因 DALY 下降 20.7% (13.9-27.7)
- 环境与职业风险下降 22.0% (15.5-28.8)
- 代谢风险上升 **49.4% (42.3-56.9)** -- 人口老化与生活方式改变
- 高 BMI 的年龄标化归因 DALY 率上升 15.7% (9.9-21.7); 高 FPG 上升 7.9% (3.3-12.9)
- 高 BMI 暴露年增 1.8% (1.6-1.9); 高 FPG 1.3% (1.1-1.5)
- 儿童生长不良的年龄标化归因 DALY 下降 71.5% (64.4-78.8); 不安全水源下降 66.3% (60.2-72.0)

**年龄分层:**

- 0-4 岁与 5-14 岁: 低出生体重与早产、不安全饮水与卫生 (WaSH) 居前
- 老年组: 代谢风险 (高 SBP, 高 BMI, 高 FPG, 高 LDL 胆固醇) 影响更大

## 剂量反应与可执行解读

- 人口层优先级: 代谢四项 (血压/血糖/BMI/血脂) + 吸烟占主导——与 E47 LE8 的四健康
  因素完全对应
- 可执行: 个体层面做的是同一件事 (血压监测与控制, 不吸烟, 控糖控重, 少 PM 暴露);
  公共卫生层面则是控烟政策, 食品糖盐政策, 空气治理

## 证据强度与局限性

- 优势: 全球最系统的归因框架, 数据来源与模型文档公开, 分层细
- 局限: 模型测算 (非直接试验); 部分地区数据缺失靠外推; 归因分值的方法学假设
  (理论最小风险暴露) 有争议; 摘要未列全 88 项细节

## 与其他证据的一致性

- 与 E47 (LE8) 一一对应; 与 E26-E30 (烟酒 BMI) 的个体效应量级互为印证;
  与 E48 (痴呆 14 因素) 的可改变因素高度重叠
