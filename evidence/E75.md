# E75. 听力损失与痴呆: 每 10 dB 听力下降, 痴呆风险增加 27%

> 层级: [← 总结 README](../README.md) · [维度速览 16-hearing](../topics/16-hearing.md) · 本页 `E75`

## 一句话结论

639 名 36-90 岁、1990-1994 年听力正常者的前瞻研究、中位随访 11.9 年: 基线听力损失严重度与
阿尔茨海默病及相关痴呆风险呈**对数线性关系, 每 10 dB 损失风险增加 27%** (HR 1.27, 95% CI 1.06-1.50);
与听力正常者相比, 轻度损失 HR 1.89 (1.00-3.58)、中度 3.00 (1.43-6.30)、重度 4.94 (1.09-22.40)。
这是"听力"作为被遗漏长寿维度最有力的证据。

## 研究设计与人群

- 设计: 前瞻性队列 (巴尔的摩老龄化纵向研究)
- 样本: 639 人, 年龄 36-90 岁; 1990-1994 年接受听力测定且当时无痴呆
- 听力定义: 较好耳 0.5、1、2、4 kHz 纯音平均阈值
  - 正常 <25 dB (n=455)
  - 轻度 25-40 dB (n=125)
  - 中度 41-70 dB (n=53)
  - 重度 >70 dB (n=6)
- 中位随访: 11.9 年 (结局判定至 2008-05-31)
- 结局: 全因痴呆 58 例, 其中阿尔茨海默病 (AD) 37 例

## 关键数字 (机器核验, 摘要原文)

| 项目 | 数值 (95% CI) |
|---|---|
| 每 10 dB 听力损失 -> 全因痴呆 | **HR 1.27 (1.06-1.50)** |
| 每 10 dB 听力损失 -> 阿尔茨海默病 | HR 1.20 (0.94-1.53), **不显著** |
| 轻度损失 (25-40 dB) -> 全因痴呆 | 1.89 (1.00-3.58) |
| 中度损失 (41-70 dB) -> 全因痴呆 | **3.00 (1.43-6.30)** |
| 重度损失 (>70 dB) -> 全因痴呆 | **4.94 (1.09-22.40)** |
| 事件数 | 全因痴呆 58; AD 37 |

## 剂量反应与可执行解读

- 清晰的**对数线性剂量反应**: 每 10 dB 增加 27% 风险, 是可直接用于风险沟通的数字
- 重度组 CI 极宽 (1.09-22.40) 因仅 6 人, 不能据此估算精确风险; 但方向与其他组一致
- 注意区分: 全因痴呆显著, **阿尔茨海默病单独看并不显著** (1.20, 0.94-1.53) -> 效应可能更多体现在
  血管性痴呆等混合类型
- 可执行: 中年起定期查听力; 有听力下降应及早验配助听器 (是否有预防痴呆的效果见 E77 的 RCT)

## 证据强度与局限性

- 优势: 听力经听力学测定 (非自报), 剂量分级细致, 对数线性关系明确, 随访 11.9 年足够长
- 局限: 样本仅 639 人, 痴呆仅 58 例 -> 统计效能有限, 重度组 CI 极宽; 观察性设计无法排除混杂
  (听力损失者可能同时有更多血管危险因素); 人群以白人为主
- 与本条目配套: E76 (meta 汇总) 与 E77 (听力干预 RCT) 共同构成听力维度的证据链

## 与其他证据的一致性

- 与 E76 (JAMA Otolaryngol 2018 meta) 一致: 听力损失与认知障碍/痴呆风险升高相关
- 与 E77 (ACHIEVE RCT) 的关系需谨慎: 干预能否降低痴呆风险, RCT 给出了限定条件下的答案
- 与本项目 README 的判断一致: 听力是主流长寿补剂叙事完全遗漏的维度, 且是**可干预**的
