# 09 · 维生素 C 全链条 (补剂 ≠ 完整食物)

> 层级: [← 总结 README](../README.md) · 本页 = 维度速览层 · 逐条分析见 evidence/ 对应条目

## 一句话结论

"血浆维 C 高 → 死亡低"的观察性关联真实存在, 但因果链三层检验全部失败:
MR 无因果 → 口服 RCT 无效 → 重症静脉大剂量无效; 且男性大剂量补剂有肾结石风险。
好处在食物不在药片。

## TL;DR (EN)

"High plasma vitamin C → lower mortality" is real observationally, but the causal chain fails at all three test layers: MR shows no causation → oral RCTs show no effect → high-dose IV in sepsis shows no effect; high-dose supplements add kidney-stone risk in men. The benefit is in foods, not pills.

## 关键数字

| 环节 | 数字 | 出处 |
|---|---|---|
| 观察性: 血浆维 C 最高 vs 最低 (32 万人) | CVD 死亡 RR 0.60 (0.42-0.78) | [E36](../evidence/E36.md) |
| 中国 16 年队列: 充足 (>28 µmol/L) vs 不足 | 全因死亡 HR 0.77 (0.63-0.95) | [E37](../evidence/E37.md) |
| 因果检验: 基因高维 C (MR, 97,203 人) | 缺血性心脏病与全因死亡 CI 均跨 1.0 (不显著) | [E38](../evidence/E38.md) |
| 抗氧化补剂 RCT meta (低偏倚试验) | β-胡萝卜素 1.07, 维 A 1.16, 维 E 1.04 (**增死亡**); 维 C 中性 | [E39](../evidence/E39.md) |
| PHS II RCT: 500 mg/d 维 C × 8 年 (14,641 男医生) | 主要 CV 事件 HR 0.99; 癌症 1.01; 全因 1.07 — 全部无效应 | [E40](../evidence/E40.md) |
| 重症: 静注 50 mg/kg q6h (CITRIS-ALI) | SOFA 差值 -0.10 (-1.23 至 1.03), P=0.86 | [E41](../evidence/E41.md) |
| VICTAS (维 C+硫胺素+氢化可的松) | 呼吸机/升压药脱离日差 -1 天, P=0.85 | [E41](../evidence/E41.md) |
| 安全性: 男性 ≥1000 mg/d 补剂 | 肾结石 OR 1.14-1.62 显著升高; 女性不显著 | [E42](../evidence/E42.md) |
| 感冒 (Cochrane): 常规补充 | 不降低发生率; 已规律补充者病程缩短成人 8%/儿童 14%; 马拉松等特宜人群 RR 0.48 | [E43](../evidence/E43.md) |

## 可执行清单

- 不为延寿/防病/救命服用维 C 补剂; 男性避免长期 ≥1000 mg/d (泡腾片常见踩坑)
- 蔬果照吃 (维 C 是蔬果的忠实标志物): 每天 500 g 级即可达到血浆充足线 28 µmol/L
- 感冒了再吃维 C 无效 (需预先饱和); 剧烈体力消耗人群 (马拉松/滑雪) 可预先补
- 教科书级警示: 观察阳性 → MR 阴性 → RCT 无效 = 标志物陷阱的完整标本
